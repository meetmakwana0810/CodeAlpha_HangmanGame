# CodeAlpha Hangman Game

## 📌 Project Overview

This project is a simple text-based Hangman game developed using Python.

The player has to guess a randomly selected word one letter at a time. The game allows a maximum of 6 incorrect guesses.

## 🎯 Features

- Random word selection
- 5 predefined words
- Letter-by-letter guessing
- Tracks guessed letters
- Maximum 6 incorrect guesses
- Win and Game Over conditions
- Console-based interface

## 🛠️ Technologies Used

- Python
- Random module
- Lists
- Strings
- While loop
- If-else conditions
- Functions
- User input/output
